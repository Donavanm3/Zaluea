Autobahn Outlaws — a browser open-world game set in Germany.

All graphics, sounds and radio music are generated procedurally at runtime — no external assets.

Map data: hand-traced outline of Germany, its cities, rivers, lakes, uplands and Autobahn network (simplified and scaled down for play).

Rendering: three.js (MIT licence).

This is a work of fiction. All characters, companies and brands in the game are fictional. Any resemblance to real persons is coincidental. Do not drive like this in real life.
